# 标签速选面板

自 `TypechoRe 2026092403 TAG` 起，标签速选功能已**整合进核心**（原
TagToText 插件已移除），无需安装插件即可使用。

## 一、功能位置

撰写文章页右侧「标签」区块，常驻展开，无收起按钮：

```text
标签
┌──────────────────────────────────────────────┐
│  搜索或输入新标签, 回车确认              [清空]   │
├──────────────────────────────────────────────┤
│  PHP 12   博客 12   更新 8   BUG 8            │
│  TpRe插件 2   RUST 1   SKILL 1 ...            │
└──────────────────────────────────────────────┘
```

- 标签云**服务端渲染**，按设置排序，可显示每个标签关联的文章数；
- 点击标签即选中（蓝底白字高亮），再次点击取消；
- 新建、尚未入库的标签以虚线边框标识。

表单仍通过隐藏的 `tags` 字段提交（逗号分隔），后端保存逻辑与原版一致。

## 二、交互说明

| 操作 | 行为 |
|:--|:--|
| 点击标签 | 选中 / 取消 |
| 搜索框输入 | 实时过滤标签云 |
| 回车 | 有精确匹配 → 切换选中；否则选中第一个匹配项；均无匹配 → 以当前输入**新建**标签 |
| 输入含逗号后回车 | 视为批量提交（`a,b,c` = 依次创建 3 个标签） |
| Backspace（搜索框为空时） | 删除最后一个已选标签 |
| ESC | 清空搜索框 |
| 清空按钮 | 清空全部已选标签 |

新建的标签名会自动剥离 `< > & " '` 与半/全角逗号（后者是隐藏字段的
分隔符，不允许出现在标签名内），防止列表被拆乱。

中文输入法组合中的回车（确认候选词）不会误触发选签/新建。

## 三、设置

在「管理 → 标签」页面右侧栏「速选面板设置」中调整：

| 设置项 | 默认值 | 说明 |
|:--|:--|:--|
| 排序方式 | 按文章数量 | `count` 按文章数由多到少 / `name` 按标签名称 |
| 载入的标签数量 | `100` | 填 `0` 表示载入全部，标签非常多时建议设置上限 |
| 隐藏没有被任何文章使用的标签 | 关 | 过滤零引用标签 |
| 在标签后面显示关联的文章数量 | 开 | 在 chip 内以小号数字显示 |

设置以 JSON 存储在 options 表的 `tagPicker` 行（`user = 0`），无 schema
变更。保存走 `tag-picker` action（对应 `Widget\Options\TagPicker`），
需要 editor 及以上权限，并校验 CSRF token。

## 四、从 TagToText 插件升级

1. **先**在后台停用并删除 TagToText 插件（避免插件记录指向不存在的
   目录，参见[部署与恢复](/guide/deployment)的「插件与数据库一致性」）；
2. 部署新版代码；
3. 到「管理 → 标签」右侧栏重新配置一次面板设置。

插件版本的面板设置不会自动迁移（数据结构不同）。

## 五、已知边界

- 标签名**不能包含逗号**（半角/全角均不行）：tags 字段本身是逗号分隔的
  扁平字符串，这是原版 Typecho 一致的限制；
- 标签云条目数受「载入的标签数量」限制，超出部分不在面板中显示，仍可
  通过搜索框输入名称新建/选中。

## 六、样式定制

面板样式位于 `admin/css/style.css`，类名统一以 `.tag-picker-` 开头：

| 类名 | 作用 |
|:--|:--|
| `.tag-picker` | 面板容器（边框、外边距） |
| `.tag-picker-bar` | 顶部输入行（搜索框 + 清空按钮） |
| `.tag-picker-cloud` | 标签云滚动区域 |
| `.tag-picker-item` | 标签 chip |
| `.tag-picker-item.tag-picker-active` | 选中态（蓝底白字） |
| `.tag-picker-item.tag-picker-new` | 新建未入库态（虚线边框） |
| `.tag-picker-num` | chip 内的文章数 |
| `.tag-picker-empty` | 空态提示 |

注意后台静态资源带全局版本号（`?v=`），修改 CSS 后需强刷浏览器。
