TypechoRe 博客平台

**TypechoRe** 是 [Typecho](https://github.com/typecho/typecho) 的积极维护 Fork 版本 —— 一款基于 PHP 的博客程序。

## 主要特性

* 支持多种数据库（MariaDB、MySQL、SQLite、PostgreSQL）
* Markdown 支持
* 插件支持
* 主题支持
* 自定义字段
* 自定义页面

## 环境要求

* PHP 8.5 或更高
* 数据库（MariaDB、MySQL、SQLite、PostgreSQL）
  * MariaDB 或 MySQL 5.5.3 或更高
  * SQLite 3.7.11 或更高
  * PostgreSQL 9.1 或更高
